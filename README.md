# Deep Learning Fundamentals & Architectures

A practical, beginner-friendly learning resource designed to make Deep Learning concepts easier to understand through structured explanations, visual learning, and model-selection guidance.

## Overview

Deep Learning includes a wide range of neural network architectures, each designed to address different types of problems. Understanding how these architectures work, how they relate to one another, and when to use them is essential for building effective AI solutions.

This repository organizes the learning journey into a series of notebooks, starting with neural network fundamentals and progressing toward sequence models, attention mechanisms, Transformers, and advanced architectures.

## Learning Path

1. **Neural Network Fundamentals & Core Architectures** — Understand neural networks, ML and DL models, tree-based methods, CNNs, VGG, and ResNet.
2. **Sequence Models & Attention Mechanisms** — Explore sequence learning, LSTM, GRU, attention, and self-attention.
3. **Advanced Architectures & Transfer Learning** — Connect Transformers with BERT, Vision Transformers (ViT), and transfer learning.
4. **Deep Learning Fundamentals & Model Selection** — Review major architectures, their applications, evaluation, and how to choose suitable models for different tasks.

## Learning Objectives

- Build a strong conceptual foundation in Deep Learning.
- Understand the intuition behind neural network architectures.
- Connect related models and understand how the field has evolved.
- Identify suitable architectures for different data types and tasks.
- Learn the role of attention, Transformers, and pretrained models.
- Develop a practical understanding of model selection and evaluation.

## Who Is This For?

- Students learning Deep Learning and Artificial Intelligence.
- Beginners who want a structured learning path.
- Machine Learning practitioners exploring neural network architectures.
- Learners preparing for research, projects, or advanced AI study.

## Learning Philosophy

The focus is on **understanding before implementation**: start with the core idea, understand how an architecture works, learn what makes it useful, and then explore where it fits into the broader Deep Learning landscape.

These notebooks are intended as a learning reference that can be revisited while studying, implementing models, and working on AI projects.
